# M.F.V. 03 — 自走工廠 / 1918

Godot 4.7のローポリ3D工場構築・戦闘ゲーム。戦車の内部に弾薬と燃料のラインを組み、資源を回収しながら5つの戦場を進みます。

**[ブラウザで遊ぶ](https://last-supply-line.dicenull-dev.workers.dev)** — PCのキーボード・マウス、スマートフォンの横持ちタッチ操作に対応。

## はじめる

ローカルではGodot 4.7で`project.godot`を開き、初回インポート後に **F5** で起動します。macOSのGodot 4.7.2 / Compatibilityで検証済みです。

起動すると専用のスタート画面にタイトルと大きな戦車が表示されます。左端の枠なしメニューから開始・再開・設定・出撃履歴を選べます。ゲーム本体は開始・再開時に読み込まれます。

スマホでは左のパッドで前後進・旋回し、画面下のPCと共通のアイコンで出撃・停止・設備選択・倉庫・メニューを操作します。狭い画面ではフッターを段組みにします。装備は倉庫で選んでから設置場所をタップ。「収納」を選んで装備をタップすると倉庫へ戻せます。縦向きにすると一時停止します。

1. タイトルの「設定」で難易度を選び、「はじめる」。見本ラインを調整し、**I**の装備一覧からドラッグして装備を配置します。
2. **Space**で出撃。生産・照準・射撃は自動、移動は手動です。**B**で車内に戻れば戦闘中もラインを変更できます。
3. ランダムな道を右上へ進み、分岐先の搬入ヤードへ入るとクリア。入った施設が次の行き先になります。報酬を選び、次戦のラインを調整します。

## 基本操作

| 操作 | 動作 |
|---|---|
| 左／右クリック・ドラッグ | 構築中の設備配置／撤去 |
| R | 配置予定の向きを回転 |
| W/S・↑/↓ | 前進／後退 |
| A/D・←/→ | その場で旋回 |
| Space | 出撃・一時停止・再開 |
| B | 車内／戦場を切替 |
| I | 装備一覧。不要品を解体して建設素材を回収 |
| Esc | 保存・配置管理・音量などのメニュー |

「ランを保存」で中断し、次回は「続きから」で再開できます。ブラウザではタブを閉じる前に保存してください。
