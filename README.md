# M.F.V. 03 — 自走工廠 / 1918

Godot 4.7のローポリ3D工場・自動戦闘ゲームです。巨大な軽戦車の内部に弾薬と燃料のラインを組み、資源を回収しながら5つの戦場を進みます。

## 起動
Godot 4.7でproject.godotを開き、F5。macOSのGodot 4.7.2 / Compatibilityで検証しています。追加アドオン・外部モデルは不要です。
初期配置には弾薬と燃料の見本ラインがあります。在庫0・停止状態から始まります。

## 操作
| 操作 | 動作 |
|---|---|
| Space／再生 | 生産・走行・戦闘の開始、一時停止、再開 |
| B／視点アイコン | 車内／外観の切替。進行は止まらない |
| Tab／屋根 | 車内側の装甲開閉と砲塔の透明度切替 |
| 左クリック・ドラッグ | 車内の設備配置 |
| 右クリック・ドラッグ | 設備撤去 |
| 1〜5 | ベルト・炉・プレス・分岐器・弾薬庫 |
| 6 | 撤去ツール |
| 7 | 燃料精製器 |
| R | 配置予定の向きを回転 |
| Q | カーソル下の設備を回転 |
| 中ドラッグ／矢印キー | 車内カメラの向き |
| ホイール | 車内カメラのズーム |
| 白旗 | ランを撤退終了 |
| 終了後の外観画面でR／回転矢印 | 新しいランの準備へ |

走行中も配置・撤去・回転できます。編集しても再生状態は変わりません。変更したマスの物資だけを失います。
開始前は、下段の見本・保存・読込・全撤去・取り消しを使用できます。これらの全体変更は走行中に行えません。
屋根を閉じた車内では、見えない床を誤編集しないよう配置を無効にします。
戦場で移動先や敵をクリック操作する必要はありません。進軍・索敵・照準・射撃は全自動です。

## 2つの生産ライン
- 廃材→精錬炉→鋼材→プレス→砲弾→砲塔直下の給弾口
- 石炭→燃料精製器→燃料缶→エンジン給油口

資源は色と形で区別できます。設備アイコンと3D設備も同じ形・配色です。
搬送は1ステップに1マス。設備の受取は全側面で、分岐器は前と右へ交互に送ります。
弾薬庫8発、砲塔の初期装填12発、燃料12缶分。満杯になると手前で止まります。
燃料がなければ走行が止まり、砲弾がなければ射撃が止まります。工場は壊れず、修復操作もありません。

## ランと資源
開始時の原料は廃材48・石炭32。原料口は有限の在庫から引き出します。
道中の資源地点は通過時に自動回収。敵残骸からも廃材を回収します。原料の積載上限は各100で、積載強化により増やせます。
画面上部は車内の加工品を含む数、右パネル下端の廃材・石炭は未投入の原料在庫です。

第1戦をクリアすると、加工時間×0.85／燃費×0.80／装填容量+4から1つ強化を選びます。第2戦以降は装填間隔×0.80と原料積載上限+25を加えた5種から、毎回3種が提示されます。装填間隔は砲弾と循環矢印、原料積載は木箱のアイコンです。
続いて車両墓場・炭鉱・兵器庫から提示される2つの行き先を選びます。
車両墓場は廃材、炭鉱は石炭が多く、兵器庫は完成砲弾を得られる代わりに守備隊が強くなります。
カードには回収資源・敵編成と総耐久・走行距離・地形と最高速度・燃料消費倍率をアイコンと数字で表示します。

次の戦場には配置・加工中の物資・原料・弾薬・燃料・車体耐久・強化を持ち越します。自動修復や無料補給はありません。
次戦は準備状態から再生で出発。5戦目には大型のボスが現れます。
全敵撃破と目的距離到達で戦場クリア、最終戦クリアでラン勝利。耐久0で敗北、白旗で撤退です。
終了後の新ランは、配置を保って初期在庫と未強化状態に戻ります。

## 戦場の表示
盾は耐久、交差砲身は撃破数、砲弾は装填在庫、燃料缶は燃料、方位アイコンは目的地までの距離です。
右パネル上端の5つのランプが現在の戦場。敵上の小さな目盛りが敵耐久、金色の輪が自動照準先です。
赤い輪は予告砲撃地点。安定した燃料供給で走り続けると、着弾地点から離れられます。
初期見本は改良の出発点です。第2廃材口から弾薬ラインを並列化すると後半の供給を増やせます。

## 現在の制限と開発状況
配布用書き出し、難易度の最終調整は開発途中です。
配置だけの保存はuser://ammo_layout.jsonに行います。ランの進行は中断保存で保持できます。
現行仕様はDESIGN.md、完成までの作業はROADMAP.md、検証手順はTESTING.mdを参照してください。

## 開始・保存・再開

起動時にアイコンメニューを表示します。左から再生／準備へ、続きから、保存、新しいラン、終了です。続きからは保存がある場合、保存はゲームに入った後に使用できます。

Escでメニューを開くと生産・走行・戦闘を停止します。再生アイコンまたはEscで元の再生状態に戻ります。フロッピーで現在のランを保存。保存後はトロフィー、失敗時は傷ついた盾のアイコンを表示します。

続きからは、配置・原料・加工中の物資・敵・飛翔弾・強化・選択候補まで復元し、停止状態で開きます。Spaceで続行してください。保存はuser://run_save.mfv、直前のバックアップは同名.bakです。主保存が破損していればバックアップを試し、どちらも読めなければ現在のゲームを変更しません。

終了アイコンとウィンドウを閉じる操作は、プレイ中なら保存成功後に終了します。保存できない場合は終了せずメニューに留まります。起動直後のメニューから終了する場合は、以前の保存を上書きしません。

## 出撃履歴

勝利・敗北・撤退時に結果を保存し、メニュー下に直近3件を表示します。左から結果アイコン、シード、クリア数／5、製造砲弾数です。最大100件をuser://run_history.jsonに保存し、直前の.bakを保持します。保持中の同一シードは最初の結果を残し、保存を読み直しても重複追加しません。履歴の破損時はバックアップを試します。保存失敗はメニュー右下の破損盾で表示します。

## 工場の設計図

メニュー上部の3枚は出撃時の配置図です。初期の見本に加え、1戦クリアで弾薬2系統、3戦クリアで弾薬庫2基付きの配置図を開放します。クリア直後に図面＋1が表示され、開放はその場で保存されます。敗北・撤退しても失いません。

新しいランの出発前にカードを押すと配置を置き換えます。金枠が現在と一致する配置です。鍵付きのカードには必要クリア数を表示します。走行中・途中戦の準備では選択できません。配置した直後なら車内の取り消しで戻せます。

設計図は既存設備の組み方を保存したもので、全構成を初回から手組みできます。2系統は生産量、弾薬庫付きは満載後の予備弾16発に重点を置きます。原料・完成品・耐久・設備上限へのボーナスはありません。燃料ラインは全図面共通です。起動時は従来の見本、新ランでは自分の配置を保持し、設計図は選んだ場合だけ適用します。

開放済み設計図は履歴と同じファイルに独立保存され、古い結果が100件の保存範囲から外れても残ります。以前の履歴ファイルは記録されたクリア数から開放状態を移行します。

## 地形・敵編成と工場の選択

| 地形 | 最高速度 | 距離あたり燃料消費 |
|---|---:|---:|
| 道路（点線の道） | 3.3m/s | ×1.00 |
| 泥濘（泥溜まりの道） | 2.8m/s | ×1.35 |
| 瓦礫（石の道） | 3.0m/s | ×1.15 |

混成は接近・迂回・重砲が各2両。襲撃隊は迂回4両と接近2両で、矢印付きの小型車両アイコンです。重砲隊は重砲4両と接近2両で、大きな砲のアイコンです。重砲隊の重砲は耐久が1増えます。カードの敵の数字は6両の総耐久で、最終戦ではボスの追加耐久も含みます。

燃料ラインを1本のまま使うか並列化するか、弾薬生産・装填速度・予備弾をどこまで増やすかを、行き先の条件と合わせて選べます。積載強化は廃材・石炭それぞれの上限を増やします。物資の無料配布や車体修復はありません。第1戦は道路・混成で固定し、初期見本から始められます。

## 回収・在庫・ラインの状態表示

資源地点の通過や敵撃破で回収すると、画面左上に資源アイコンと「＋実際に積めた数」を表示します。満載で積めなかった分は満載箱と「−積めなかった数」です。既存の在庫から引かれた数ではありません。近接する同種の回収は合算し、再生時間4秒で消えます。一時停止中は表示を保持します。

車内では、接続が切れたプラグが出口未接続、形の異なる素材と赤線が素材違い、空箱が原料・弾薬・燃料切れ、詰まった箱が満載を示します。問題のあるマスに表示し、屋根を閉じると隠れます。搬送待ちのベルト全部には印を付けません。アイコンは配置操作を妨げません。

設備にカーソルを合わせると右の設備欄に状態と関連素材を表示します。砂時計は入力待ち、時計は加工中、遮断板は出口待ち、チェックは搬送可能です。原料在庫は空なら赤、満載なら金。外観の弾薬・燃料の数値も空なら赤くなります。

## 音量と効果音

Escメニュー下部のスピーカーでミュート／解除、真鍮のつまみで音量を0〜100に調整します。初期値は35。設定はuser://audio_settings.jsonに保存し、次回起動にも引き継ぎます。保存に失敗すると設定欄に破損盾を表示し、その回の音量変更は有効なままです。破損時は.bakを試し、両方読めなければ初期値で開きます。

走行中のエンジン、加工完了、砲撃、着弾・被弾、回収をそれぞれの音で表します。燃料切れで走行が止まればエンジン音も止まります。Space・Escで停止したとき、撤退・ラン切替・保存からの復帰時も古い音を止めます。ミュートしてもゲームは進みます。

## 画面サイズ

最小ウィンドウは960×628です。1440×940の配置比率を保って拡大・縮小し、画面比率が異なる場合は余白を入れます。960×628、1024×768、1280×720、1440×940、1920×1080で実クリック・配置・視点・Tab・Escを検証しています。

## ゲームデータの書き出し

次の手順はGodot 4.7でPCKを書き出し、空の作業フォルダから起動・生産・射撃・走行を自動確認します。

~~~sh
python3 tools/export_pack.py --godot /Users/dice/Downloads/Godot.app/Contents/MacOS/Godot
~~~

出力はbuild/mfv03.pckと検証情報・SHA-256を含むbuild/mfv03-manifest.jsonです。試験コード・プレビュー画像・作業用ツールはPCKに含めません。PCKはGodotランタイムが必要なゲームデータで、単体アプリではありません。

~~~sh
/Users/dice/Downloads/Godot.app/Contents/MacOS/Godot --main-pack /absolute/path/to/mfv03.pck
~~~

macOSの書き出しプリセットも付属します。単体アプリの書き出し・実行確認は対応する書き出しテンプレートの導入後に行います。現時点では署名や公証を行っていません。


## macOS単体アプリの書き出し

Godot 4.7.2の公式Export Templatesを導入し、次を実行します。

~~~sh
python3 tools/export_macos.py --godot /Users/dice/Downloads/Godot.app/Contents/MacOS/Godot
~~~

build/MFV03.zipに、Apple Silicon・Intel両方の実行ファイルを含むアプリを生成します。展開したAMMO LINE LAB.appはGodotエディターを別途必要としません。内部名は既存の保存先との互換性のため維持しています。

ビルドは一時フォルダへ展開し、ソースを参照しない画面なし／画面あり起動を検証します。mfv03-macos-manifest.jsonにGodot版、コミット、変更有無、SHA-256を記録。署名・公証なしのローカル試作版です。Intel側は実行ファイルの同梱のみ確認し、実機動作はApple Siliconで検証しています。
