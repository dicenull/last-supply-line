# M.F.V. 03 — 自走工廠 / 1918

Godot 4.7のローポリ3D工場構築・戦闘ゲーム。戦車の内部に弾薬と燃料のラインを組み、資源を回収しながら5つの戦場を進みます。

**[ブラウザで遊ぶ](https://last-supply-line.dicenull-dev.workers.dev)** — PCのキーボード・マウスで操作。タッチ操作は未対応です。

## はじめる

ローカルではGodot 4.7で`project.godot`を開き、初回インポート後に **F5** で起動します。macOSのGodot 4.7.2 / Compatibilityで検証済みです。

1. タイトルで難易度を選び、「準備へ」。弾薬・燃料の見本ラインから構築を始めます。
2. **Space**で出撃。生産・照準・射撃は自動、移動は手動です。戦闘中はラインを変更できません。
3. ゴールの搬入ヤードへ入るとクリア。報酬と経路を選び、次の戦場に向けてラインを調整します。

## 基本操作

| 操作 | 動作 |
|---|---|
| 左／右クリック・ドラッグ | 構築中の設備配置／撤去 |
| R | 配置予定の向きを回転 |
| W/S・↑/↓ | 前進／後退 |
| A/D・←/→ | その場で旋回 |
| Space | 出撃・一時停止・再開 |
| B | 車内／戦場を切替 |
| Esc | 保存・配置管理・音量などのメニュー |

「ランを保存」で中断し、次回は「続きから」で再開できます。ブラウザではタブを閉じる前に保存してください。
