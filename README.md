# M.F.V. 03 — 自走工廠 / 1918

WW1末期を思わせる架空のローポリ3D戦車の内部に、弾薬ラインを構築するGodotプロトタイプです。簡略化した菱形履帯、中央前方上部の半透明な全周旋回砲塔、短砲身、排気筒、真鍮の計器を備えています。特定の実在戦車の再現ではありません。

## 起動

Godot **4.7**で `project.godot` を開き、F5。macOS / Godot **4.7.2 stable** / Compatibilityレンダラーで検証しています。追加アドオンや外部モデルは不要。戦車・設備・物資はすべてGodot内で生成する3Dメッシュです。

## 車内に配置する

初期画面は屋根を外した断面表示です。戦車の床板が14×8の配置区画になっています。左後部の2つの回収箱から廃材を送り、炉で鋼材、プレスで砲弾に加工し、砲塔直下の給弾口へ届けます。

設備は3Dの床を直接クリックして設置します。カメラの向きを変えても同じ区画を選択できます。固定入出口の5区画には設置できません。車内の柱は撤去済みです。

| 操作 | 機能 |
|---|---|
| 左クリック・ドラッグ | 選択した設備を設置・置換 |
| 右クリック・ドラッグ | 撤去 |
| 1 / 山形矢印 | 搬送ベルト |
| 2 / 炎の炉 | 精錬炉 |
| 3 / プレス | 砲弾製造機 |
| 4 / 分岐矢印 | 分配器 |
| 5 / 弾薬棚 | 弾薬庫 |
| 7 / 蒸留塔 | 燃料精製器 |
| 6 / ゴミ箱 | 撤去ツール |
| R | 新しく置く設備の出力方向を回転 |
| Q | カーソル下の既存設備を回転 |
| Space / 再生・停止ボタン | 試運転の開始・停止 |
| Tab / 屋根アイコン | 外観と車内の切替。砲塔も外観では不透明、車内では半透明。屋根を閉じている間は配置不可 |
| 中ボタンドラッグ / 矢印キー | カメラの向き・見下ろす角度を変更 |
| ホイール | 拡大・縮小 |
| カメラアイコン | カメラを初期位置に戻す |
| Z / 戻る矢印 | 配置を1手戻す |

配置を変更すると自動停止します。変更したマスの物資のみ破棄され、それ以外は残ります。履歴を戻す場合は全物資と計測値をリセットします。

## 操作盤

画面内には説明文を配置せず、アイコンと数値で示しています。

- 上部：廃材・鋼材・砲弾の現在数。再生・停止、屋根の切替。
- 右の針式計器：直近30秒の発射速度。毎分90発で目盛りの上限。
- 砲アイコン横の%：要求された試射に弾が間に合った割合。時計横は稼働秒数。
- プレス横の数値：累計製造数。砲横の数値：累計発射数。
- 12の保管枠：試射待ちの砲弾数。
- 設備を指すと、右側に素材アイコンと加工ゲージを表示。
- 下段の30 / 60 / 90：試射ペースを毎分単位で切替。
- 下の操作盤：工具、レシピの絵、配置方向、保存など。

下段左から接続図＝見本1系統、フロッピー＝保存、下矢印入りフォルダ＝読込、ゴミ箱＝全撤去、戻る矢印＝元に戻す。斜線入りの円形矢印は配置を残した物資・計測リセットです。

## 立体の物資と設備

廃材は錆びた金属片、鋼材は灰青色のインゴット、砲弾は真鍮色の薬莢と尖った弾頭で表現します。物資はベルト、機械、弾薬棚の間を滑らかに移動し、一時停止するとその場に留まります。

精錬炉の火が加工中に点灯し、砲弾機のプレスが動きます。弾薬棚には実際の砲弾を並べます。給弾口へ届いた砲弾だけを使い、全周砲塔が四方向へ90度ずつ順番に試射します。砲塔は滑らかに旋回し、発射時には銃口の光、砲身の反動、砲口方向へ飛ぶ曳光弾を表示します。屋根を閉じても工場の運転は続きます。

## ルール

- 廃材口2か所、各最大60個/分。原料は試験用の無限供給。
- 廃材1 → 精錬炉1.5秒 → 鋼材1 → 砲弾機2秒 → 砲弾1。
- 搬送は0.25秒で1区画。各機械は基本1物資を保持し、出力してから次を受け取るため、加工時間以外に受け渡し時間もかかります。
- 分配器は正面・右折方向へ交互に出力。合流は入力方向を順番に優先します。
- 弾薬庫8発、試射待ち12発。満杯になると手前で待ちます。
- 精錬炉4台、砲弾機4台、分配器6台、弾薬庫3台まで。配置は無料。
- 弾薬と燃料のラインを構築し、対戦画面で供給を検証します。修復・ライン破損・報酬はありません。

見本は約26〜28発/分の1系統。分配・追加機械・2つ目の入口を使って並列化を試してください。性能を比べるときは計測をリセットし、120秒ほど動かして直近30秒の値を比較します。

## 保存と検証

配置は `user://ammo_layout.json` に保存。以前の弾薬ライン専用版と同じ形式です。カメラ位置・稼働中の物資・計測値は保存しません。終了時の自動保存はありません。

```sh
godot --headless --path . --script res://tests/factory_test.gd
godot --path . --script res://tests/tank_ui_test.gd
```

`godot` はGodot実行ファイルのパスに置き換え可能。3D UIテストは表示可能なデスクトップが必要です。

- `scripts/factory.gd`：物流と生産のルール
- `scripts/tank_world.gd`：3D戦車・地面・設備・物資・カメラ
- `scripts/factory_view.gd`：操作盤・入力・保存

独立したゲームとしての書き出し、他OS、低性能GPU、音声は今回未対応・未検証です。

## 外観の簡略化・ドット絵UI

車体の細かいリベットや多数の履帯リンクを削り、大きな平面と少数の車輪で形を表現しています。楔形の上部操縦室と固定側面砲を、大型の半透明な全周砲塔と砲身に変更。土台と車内14×8の配置領域は維持しています。

UIアイコンは32×32ピクセルのオリジナル絵柄。輪郭、影、ハイライト、金属・木材の色差をピクセル単位で描き、最近傍表示で輪郭をぼかしません。アイコン定義は `scripts/pixel_icons.gd`。画面内に説明文はありません。

砲塔の試射は敵やダメージの追加ではなく、製造・供給結果を見せる表現です。空弾薬では発砲せず、停止すると旋回と弾の移動も止まります。

## 砲塔の位置と透明度

砲塔を車体の中央より前方、左右中央の上部に配置。直径6.8で、履帯を含む車体幅の約58%、装甲車体幅の約76%を占めます。砲塔高さは1.8、砲身も比例して拡大しています。Tab／屋根アイコンで装甲を閉じると砲塔・砲身・基部は不透明になり、開くと元の半透明に戻ります。車内表示時の砲塔本体の不透明度は12%、縁は18%、砲身と基部は22%。下の工場を見ながら操作でき、砲塔は床へのクリックを妨げません。半透明部品は影を落とさず、工場の視認性を保ちます。弾の発射位置は拡大後の砲口の実位置を使います。

### 設備と入出力の見分け方

精錬炉は赤い炉と煙突、プレスは青灰色の門型フレームと上下する金型、弾薬庫は砲弾の意匠を付けた木製ラック、回収口はスクラップ入りのホッパーです。ツールのドット絵も同じ形と配色にしています。

設備の真鍮色の送り出し台が出口、青緑のコの字型受け口が入口です。細かな矢印は付けていません。コンベアと分岐器は従来のシンプルな表示に戻し、元からある中央の方向表示だけを残しています。入口は隣の設備が送り込む側に表示し、未接続では後ろ側に表示します。既存の仕様どおり、材料はどの側面からでも受け取れます。設備を回転すると出口も回り、接続に合わせて入口表示が更新されます。画面内には説明文を追加していません。

弾薬供給口は砲塔直下の1マス（内部座標9,4）に固定しています。旧車体端の供給口は空き区画となり、車内の柱4本とその配置制限も撤去しました。見本ラインは新しい供給口へ接続します。

## 対戦画面

工場でラインを用意し、上部の交差砲身アイコン／Bで対戦画面へ移ります。同じ工場が裏で稼働し、砲塔は近い敵を自動照準して、届いた砲弾だけを使います。弾切れの間は射撃しません。試運転の空撃ちは対戦中に停止します。

敵戦車6両が段階出現し、各3発で撃破。通常・迂回・重砲タイプが接近します。赤い輪は敵の予告砲撃地点。着弾時に輪の範囲にいると耐久が10減ります。全6両撃破と100m到達で勝利、耐久0で敗北です。右側に耐久・撃破数・弾薬・燃料・進行距離・速度、敵の上に残り耐久を表示します。

Spaceは一時停止。B／工場アイコンで工場に戻ると対戦も生産も停止し、配置を見直せます。再びBで同じ対戦を続行。勝敗後はR／回転矢印で再戦し、配置を保ったまま物資・戦績・敵・耐久をリセットします。初期配置は空なので、まず自分でラインを組むか見本ボタンを使ってください。修復・ライン破損・オンライン対戦はありません。

## 石炭から燃料を作る・走行する

車内左後部の石炭口（0,7）から、ベルト→燃料精製器（7キー）→ベルト→エンジン給油口（4,7）へ接続します。石炭1個を2秒で燃料1缶に変換し、給油口は最大12缶分を保持。石炭の塊と青緑の燃料缶がライン上を流れます。見本ボタンには弾薬・燃料の両ラインが入っています。

対戦中は燃料があれば自動前進します。最高3.3m/s、1mごとに燃料0.12を消費。燃料切れでは停止しますが、弾薬があれば射撃できます。戦闘は全自動です。進軍・索敵・照準・射撃を自動で行い、金色の輪で現在の標的を示します。戦場をクリックしても移動先や攻撃対象は変わりません。燃料供給が続けば進軍によって予告砲撃地点から離れられます。カメラは車体を追い、地形・履帯跡・残骸が後方へ流れます。
