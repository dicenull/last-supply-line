# M.F.V. 03 — 自走工廠 / 1918

Godot 4.7のローポリ3D工場構築・戦闘ゲームです。巨大な軽戦車の内部に弾薬と燃料のラインを組み、資源を回収しながら5つの戦場を進みます。

## 起動

**[ブラウザで遊ぶ](https://last-supply-line.dicenull-dev.workers.dev)** — PCのキーボード・マウスで操作します。

ブラウザ版のビルド・ローカル起動・Cloudflare Workersへの公開手順は [Web版の手順](web/README.md) を参照してください。

macOSのGodot 4.7.2 / Compatibilityで検証しています。追加アドオン・外部モデルは不要です。

この開発環境では、ターミナルで次のコマンドを実行するとゲームが起動します。実行時の作業フォルダは問いません。

```sh
/Applications/Godot.app/Contents/MacOS/Godot --path /Users/dice/Proj/last-supply-line
```

別の環境では、Godot実行ファイルとプロジェクトフォルダのパスを置き換えてください。パスに空白がある場合は、そのパスをダブルクォートで囲みます。

Godotエディターから起動する場合：

1. Godot 4.7のプロジェクトマネージャーで、このフォルダの `project.godot` をインポートして開きます。
2. 初回のインポート処理が終わったら、右上の実行ボタンまたは **F5** で起動します。

起動後はメニューの「難易度」でイージー／ノーマル／ハードを選び、「準備へ」を選びます。難易度は第1戦の出発前に変更でき、ラン途中では固定です。保存したランを再開する場合は「続きから」を選びます。初期配置には弾薬と燃料の見本ラインがあり、砲弾・燃料は在庫0、停止状態から始まります。構築が済んだら **Space** またはフッターの「出撃」で戦闘へ進みます。ラインはそのステージのクリアまで固定され、生産と射撃が自動で始まります。自機は **WASD／矢印キー** で移動します。**B** で車内／戦場を切り替え、**Esc** で保存などのメニューを開けます。

## 操作
| 操作 | 動作 |
|---|---|
| Space／出撃・停止・再開 | 構築を確定して戦闘へ出撃。戦闘中は一時停止／再開 |
| WASD／矢印キー（戦闘中） | 現在の車体方向にW/↑で前進、S/↓で後退。A/←・D/→でその場の超信地旋回。キーを離すと停止 |
| B／視点アイコン | 車内／外観の切替。進行は止まらない |
| Tab／Escメニューの屋根 | 車内側の装甲開閉と砲塔の透明度切替 |
| 左クリック・ドラッグ | 構築中の設備配置 |
| 副砲の給弾マスを左ドラッグ | 構築中に空きマスへ移設。副砲本体も追従 |
| 右クリック・ドラッグ | 構築中の設備撤去 |
| 1〜7 | 現在の設備ページの各ツールを選択 |
| 8／設備ページアイコン | 基本設備 → 分岐・フィルター → 高速加工・備蓄・防御を切替 |
| 9 | 防御ブロックを選択（構築中） |
| R | 配置予定の向きを回転 |
| Q | カーソル下の設備を回転 |
| 中ドラッグ／矢印キー（構築中） | 車内カメラの向き |
| ホイール（構築中） | 車内カメラのズーム |
| Escメニューの白旗 | ランを撤退終了 |
| 終了後の外観画面でR／回転矢印 | 新しいランの準備へ |

構築中にマスへカーソルを合わせると、選択設備の半透明プレビューを表示し、山形の蓋で出力方向を示します。Rで配置予定を90度ずつ回転し、クリックすると表示中の向きで設置します。分岐器は各出力先を表示し、置けない場所や素材不足では赤くなります。コンベアは角形パイプで、設置後も天面の山形の継ぎ目が流れる向きを示します。

パイプは隣接設備の搬送方向に合わせて直線・L字・分岐へ自動で形状が変わります。設備の接続口も同じ高さの継ぎ手でつながります。回転・撤去・部位破壊に合わせて接続表示が更新され、配置プレビューにも接続予定の形を表示します。

構築フェーズでは従来どおり配置・撤去・回転・副砲移設ができます。戦闘フェーズではライン全体をロックし、一時停止・Escメニュー・車内表示・保存復帰でも変更できません。クリア後、アイテム報酬・経路選択を経て、次戦の構築に戻ります。構築時の編集では変更したマスの物資だけを失います。
配置の保存・読込・全撤去・取り消しはEscメニューの「配置・車両」にまとめています。出発前に使用でき、走行中はメニューで停止しても無効です。見本の再配置は新ラン出発前に「配置テンプレート」の標準配置から行います。
屋根を閉じた車内では、見えない床を誤編集しないよう配置を無効にします。
戦闘中は移動だけを手動で操作し、索敵・照準・射撃・生産は自動です。Wで車体の向いている方向へ前進、Sでそのまま後退します。A/Dは左右の履帯を逆方向に動かす超信地旋回で、車体の中心位置を動かさず左／右へ向きを変えます。W/SとA/Dを同時に押すと曲がりながら走行します。旋回だけでも履帯の走行量に応じた燃料を消費します。無入力では停止し、燃料切れでは前後移動も旋回もできませんが、生産と在庫弾の射撃は続きます。車内の確認中も移動キーは有効です。

## 2つの生産ライン
- 廃材→精錬炉→鋼材→プレス→砲弾→砲塔直下の給弾口
- 石炭→燃料精製器→燃料缶→エンジン給油口

資源は色と形で区別できます。設備アイコンと3D設備も同じ形・配色です。
搬送は1ステップに1マス。設備の受取は全側面で、分岐器は前と右へ交互に送ります。
弾薬庫8発、砲塔の初期装填12発、燃料12缶分。満杯になると手前で止まります。
燃料がなければ走行が止まり、砲弾がなければ射撃が止まります。被弾すると車体とライン設備が損傷しますが、コースクリア時に無料で一括修復します。

## ランと資源
原料口は有限の在庫から引き出します。開始時の原料と敵数は難易度で変わります。

| 難易度 | 廃材／石炭 | 第1戦→第5戦の敵数 | 1波の敵数 |
|---|---:|---:|---:|
| イージー | 64／44 | 10→22 | 3 |
| ノーマル | 48／32 | 12→24 | 4 |
| ハード | 42／28 | 18→30 | 5 |

イージーは被害を抑え、砲撃予告を長くし、道中の原料回収量も増やします。ハードは敵の密度・攻撃頻度が高く、予告と初期資源が少なくなります。敵は全難易度で一撃撃破です。
道中の資源地点は通過時に自動回収。敵残骸からも廃材を回収します。廃材・石炭の所持上限はなく、回収した分をすべて蓄えられます。
中間の補給地点は、行き先に合わせた小型クレーン・石炭積込台・弾薬荷捌き場で表示します。回収後は物資がなくなり、信号腕が下がってランプが消えます。空の施設はその場に残り、再通過しても二重には回収できません。
ヘッダーの廃材・石炭は未投入の所持数、鋼材はライン上の数量です。砲弾と燃料は砲塔・タンクの残量／容量を表示します。

ステージクリアごとに、装備17種から重複なしで3候補が抽選され、1つを選んで入手します。装備は資源を払わずその場で装着し、取得済み装備は次の抽選から除かれます。最終戦も報酬を選んでからラン完了です。選択待ちの候補は保存され、読み直しても変わりません。

ライン設備は、構築フェーズで廃材と石炭を消費して設置します。初期の標準ラインは組立済みで支給されます。フッターの数字は現在の素材と搭載上限で追加できる数、カーソルを合わせると建設費が表示されます。撤去は建設費を全額返却、置換は差額だけ精算、回転は無料です。取り消し・配置読込・テンプレート適用にも同じ精算が適用され、素材不足なら配置を変更しません。戦闘中は編集できません。

防御ブロックは最初から使えます。設備の3ページ目の盾アイコン、または **9** キーで選び、廃材5で設置します（最大8個）。自分と周囲8マスへの被弾を3回まで肩代わりし、その被弾の車体ダメージも半減します。3発目で防御ブロックが壊れ、次の被弾から設備が破壊されます。砲弾・地雷の両方に有効で、残り耐久は積み重なった装甲板の数で表示します。素材は搬送しないため、ラインの横へ設置してください。コースクリア時に耐久と破壊済みブロックを無料修復します。

死亡するたびに、未解放の設備設計図をランダムで1種類、恒久解放します。基本6種は最初から使用でき、高炉・動力プレス・フィルターなどの追加10種を解放できます。敗北画面のヘッダーに設備名を表示し、次のランから素材で建設できます。クリア・撤退では設備設計図は増えません。同じ死亡のセーブを読み直しても重複獲得しません。未解放の設備はフッターで無効になり、Escメニューに解放数を表示します。

| 設備 | 廃材 | 石炭 |
|---|---:|---:|
| 搬送路 | 1 | 0 |
| 精錬炉／砲弾プレス | 6 | 1 |
| 分配器 | 3 | 0 |
| 備蓄庫 | 4 | 0 |
| 燃料精製機 | 6 | 2 |
| 素材分岐器／一括搬送庫 | 6 | 1 |
| 優先分岐器 | 5 | 1 |
| 三方向分配器 | 7 | 1 |
| 廃材／砲弾／燃料フィルター | 3 | 0 |
| 高炉 | 10 | 3 |
| 動力プレス | 10 | 2 |
| 燃料備蓄庫 | 6 | 1 |
| 防御ブロック | 5 | 0 |

副砲を入手すると、車内に専用の給弾マスが1つ増えます。8種の副砲と主砲は別々の弾薬在庫を持つため、各給弾口へラインを接続してください。副砲は空の在庫から始まり、そのマスへ届いた砲弾だけを使って独立射撃します。迫撃砲・三連散弾砲・蓄電誘導砲は1射に2発、ほかの砲は1発を消費します。迫撃砲は範囲攻撃、散弾砲は前方最大3両への同時射撃、誘導砲は9m以内の次の敵へ最大2回連鎖します。各副砲の容量は主砲と同じで、初期12発です。
車内で副砲の給弾マスを空きマスへ左ドラッグすると、車体上の副砲も同じ位置へ移動します。弾薬と装填待ち時間は保持します。移設は構築中だけ可能です。既存設備・固定口・他の副砲への上書きはできません。副砲の在庫は給弾マスにカーソルを合わせるとヘッダーに表示されます。通常のヘッダーの砲弾数は主砲の在庫です。
追加装甲は被ダメージを25%軽減します（端数切り上げ）。配置・素材・装備・副砲の位置と弾薬は同じランの次戦へ持ち越し、中断保存にも含まれます。新ランでは副砲の給弾マスも撤去されます。

続いて車両墓場・炭鉱・兵器庫から提示される2つの行き先を選びます。旧保存で偵察地図を取得済みの場合は3択を維持します。報酬と次の経路は画面中央のポップアップで選択します。車両墓場は廃材、炭鉱は石炭が多く、兵器庫では完成砲弾を得られます。
カードには回収資源・主要な敵・敵数・地形を表示し、2択時は距離・速度・燃料倍率も表示します。カーソルを合わせると全敵種と移動条件を確認できます。

コースクリア時に車体耐久を100まで回復し、壊れた設備を元の位置・向きで無料修復します。次の戦場には修復後の配置・無傷の設備で加工中の物資・原料・弾薬・燃料・強化を持ち越します。失った物資や消費済みの弾薬・燃料は補給しません。
次戦は構築フェーズでラインを調整し、出撃で出発。5戦目には大型のボスが現れます。
敵は通常車両・重砲・ボスを含め、砲弾1発の着弾で倒せます。着弾待ちの敵には追加発射せず、次の敵へ照準を移します。以前の保存から再開した敵にも1発撃破が適用されます。
コース終点の施設にある搬入ヤードへ自車両の中心が入ると戦場クリアです。敵の全滅は不要で、敷地の横を通り過ぎるだけではクリアになりません。最終戦も同じ侵入条件でクリアし、報酬選択後にラン勝利となります。耐久0で敗北、白旗で撤退です。

ゴール施設は行き先に対応し、車両墓場は回収クレーン、炭鉱は石炭積込設備、兵器庫は弾薬倉庫です。門の内側にある縁取りされた床が到着区画です。コースが進むと資材置き場が増え、最終戦は見張り塔も備えます。

道中には鉄柵と交差鋼材の対戦車障害物が左右交互に並び、空いた側へ蛇行して進みます。車体全体に衝突判定があるため、旋回時にも余裕を取ってください。障害物越しにも照準・射撃でき、敵味方の砲弾は通過します。地面の円盤状の地雷は金属色の本体と上面・縁の赤いアクセントで表示します。踏むと車体と付近のラインが損傷し、爆発跡が残ります。同じ地雷は再爆発しません。

蛇行分の燃料に合わせて道中の石炭を増やし、補給施設は通路の外側へ配置しています。障害物は新しく生成するコースから登場し、旧セーブの走行中コースは従来の配置で再開します。
新ランでは標準ラインと難易度ごとの初期素材に戻り、獲得装備・増設設備・取り消し履歴をリセットします。解放済みの設備設計図と配置テンプレートは残ります。

## 戦場の表示
盾は耐久、交差砲身は撃破数、砲弾は装填在庫、燃料缶は燃料、方位アイコンは目的地までの距離です。
距離欄はゴール区画までの最短距離を「あとNm」で表示し、区画内では「あと0m」になります。横に逸れると横方向の距離も反映し、施設の横まで来ても区画外なら0mになりません。Bの戦闘画面では自車両を左下に置き、右上へ続く進路を広く見渡せます。敵は道路前方の画面外から走って入り、接近型は正面へ、迂回型は反対側の車線へ寄り、重砲は少し先から迎撃します。射撃は画面内で各砲の射程へ入ってから始まります。主砲は基本36m、長砲身砲は48m。敵の狙撃砲・迫撃砲・指揮車は48m、ほかは42mから攻撃を開始するため、増設砲と早い弾薬供給に意味があります。
ヘッダー左側の「1/5」などの数値が現在の戦場。敵上の小さな目盛りが敵耐久、金色の輪が自動照準先です。状態表示は1行にまとめ、汎用の操作完了チェック表示は省いています。
右側パネルをなくし、中央の車内／戦場を横幅いっぱいに表示します。ヘッダーは表示専用で、耐久・弾薬・燃料・距離・原料・設備状態をまとめています。構築中のフッターは設備選択・回転・視点切替・出撃・Escメニューの1段です。戦闘中は設備ツールを隠し、移動キーと「ライン固定」、視点切替・停止／再開・Escメニューを表示します。配置管理、カメラ初期化、装甲開閉、撤退はEscメニューにあります。報酬・行き先は背景を暗くした中央ポップアップに表示し、フッターを広げたり入れ子にしたりしません。試運転用の計器と発射速度切替、試運転リセットは表示しません。
赤い輪は予告砲撃地点。移動して着弾地点から離れると回避できます。予測砲撃には途中で方向を変える判断も必要です。
被弾すると車体耐久に加え、着弾地点の近くにあるライン設備が最大1マス破壊されます。搬送路・生産機・分岐・備蓄庫が対象で、そのマスの物資も失います。無傷の系統と装填済みの弾薬は残ります。破壊跡は瓦礫と赤い×で表示し、Bで車内を見ると切れた場所を確認できます。戦闘中は再建できません。コースクリア時に、報酬を選ぶ前に全設備を無料修復します。破壊時の位置・設備種別・向きも中断保存に含むため、再開後も元のラインへ復旧します。破壊による素材返却はなく、敗北・撤退では修復しません。固定の原料口・エンジン口・主砲／副砲の給弾口はこの部位破壊の対象外です。
初期見本は改良の出発点です。第2廃材口から弾薬ラインを並列化すると後半の供給を増やせます。

## 現在の制限と開発状況
Web版はCloudflare Workersで公開しています。スマートフォン向けのタッチ操作は未対応です。難易度は引き続き調整できます。
配置だけの保存はuser://ammo_layout.jsonに行います。ランの進行は中断保存で保持できます。
現行仕様はDESIGN.md、完成までの作業はROADMAP.md、検証手順はTESTING.mdを参照してください。

## 開始・保存・再開

起動時にアイコンと日本語ラベルの1列メニューを表示します。各行は32px、内側の余白は4pxです。上から準備へ（プレイ中はゲームに戻る）、続きから、ランを保存、新しいラン、終了です。続きからは保存がある場合、ランの保存はゲームに入った後に使用できます。
その下に配置保存・配置読込・全撤去・取り消し・視点初期化・装甲開閉・撤退、配置テンプレート、音声設定を縦に並べています。配置ファイルがない場合の読込、履歴がない場合の取り消し、終了済みランの撤退は無効です。成否は最下部に「完了／操作失敗」で表示します。

Escでメニューを開くと生産・走行・戦闘を停止します。「ゲームに戻る」またはEscで元の再生状態に戻ります。「ランを保存」で現在のランを保存し、成否をメニュー最下部に表示します。

続きからは、配置・原料・加工中の物資・敵・飛翔弾・装備・選択候補まで復元し、停止状態で開きます。Spaceで続行してください。戦闘中の保存はライン固定のまま復帰し、移動キーの押下状態は引き継ぎません。保存はuser://run_save.mfv、直前のバックアップは同名.bakです。主保存が破損していればバックアップを試し、どちらも読めなければ現在のゲームを変更しません。

終了アイコンとウィンドウを閉じる操作は、プレイ中なら保存成功後に終了します。保存できない場合は終了せずメニューに留まります。起動直後のメニューから終了する場合は、以前の保存を上書きしません。

## 出撃履歴

勝利・敗北・撤退時に結果を保存し、メニュー下に直近2件を表示します。左から結果アイコン、シード、クリア数／5、製造砲弾数です。最大100件をuser://run_history.jsonに保存し、直前の.bakを保持します。保持中の同一シードは最初の結果を残し、保存を読み直しても重複追加しません。履歴の破損時はバックアップを試します。保存失敗はメニュー最下部に表示します。

## 配置テンプレート

メニューの「配置テンプレート」には出撃時の配置を3行で表示します。初期の見本に加え、1戦クリアで弾薬2系統、3戦クリアで弾薬庫2基付きの配置図を開放します。クリア直後に図面＋1が表示され、開放はその場で保存されます。敗北・撤退しても失いません。

新しいランの出発前に配置テンプレートの行を押すと配置を置き換えます。金枠と「選択中」が現在と一致する配置です。鍵付きの行には必要クリア数を表示します。走行中・途中戦の準備では選択できません。配置した直後ならメニューの取り消しで戻せます。

配置テンプレートは既存設備の組み方を保存したもので、全構成を初回から手組みできます。2系統は生産量、弾薬庫付きは満載後の予備弾16発に重点を置きます。原料・完成品・耐久・設備上限へのボーナスはありません。燃料ラインは全図面共通です。新ランと出発前の難易度変更では標準ラインと初期素材に戻ります。テンプレート適用は現在の配置との建設費の差額を精算します。

設備設計図・配置テンプレートの解放状態は履歴と同じプロフィールファイルに独立保存され、古い結果が100件の保存範囲から外れても残ります。以前の履歴ファイルは記録されたクリア数から配置テンプレートを移行します。新設備の解放は更新後の新しい死亡から始まります。古いランの保存を読んでも、設備設計図の恒久解放は巻き戻りません。旧保存の配置・素材は保持し、報酬選択待ちは装備の抽選へ移行します。

## 地形・敵編成と工場の選択

| 地形 | 最高速度 | 距離あたり燃料消費 |
|---|---:|---:|
| 道路（点線の道） | 3.3m/s | ×1.00 |
| 泥濘（泥溜まりの道） | 2.8m/s | ×1.35 |
| 瓦礫（石の道） | 3.0m/s | ×1.15 |

敵は16種で、ステージごとに新しい対処を要求します。

| 戦場 | 新しく登場する敵と狙い |
|---|---|
| 第1戦 | 標準・迂回・重砲・偵察車。給弾と燃料の基本を確認 |
| 第2戦 | 狙撃砲車・迫撃砲車・突破戦車・火薬運搬車。長射程・範囲攻撃・後方への突破に対応 |
| 第3戦 | 防塞戦車・爆雷車・物資輸送車・斉射ロケット車・爆槍突撃車。密集への火力と回収資源の使い道を選択 |
| 第4戦 | 連装砲車・観測指揮車・工兵突撃車。三連射・味方支援・予測砲撃に対応 |
| 第5戦 | 全16種と大型ボス。積み上げた装備・供給ラインを活用 |

第1戦は道路固定。以降は地形と資源の違いに合わせて経路を選びます。クリア報酬で選んだ装備に合わせて、次の構築フェーズでラインを組み替えられます。

設備は基本7種（防御ブロックを含む）に10種を追加した全17種です。素材分岐器・優先分岐器・三方向分配器・一括搬送庫・廃材／砲弾／燃料フィルターで、各砲への配分を組み替えられます。高炉は石炭、動力プレスはタンク内の燃料を追加消費して加工を高速化します。燃料備蓄庫は燃料缶8個を保持します。設備ページは **8キー** で切り替え、ツールチップで効果を確認できます。

火薬運搬車を撃つと周囲11m以内の敵が誘爆します。斉射ロケット車は横に広く5発を発射し、爆槍突撃車は近づいて自爆します。近づく順序や通る位置で対処を変えられます。

破砕信管は全砲の爆発範囲を4m広げ、回転式装填機は全砲の発射間隔を20%短縮します。新装備もステージクリアの3択に入り、副砲には専用の生産・給弾ラインが必要です。

## 回収・在庫・ラインの状態表示

資源地点の通過や敵撃破で回収すると、ヘッダーの該当資源欄に現在量と「＋回収数」を1行で表示します。廃材・石炭はすべて回収し、砲弾だけは装填容量を超えた分を「−積めなかった数」で表示します。近接する同種の回収は合算し、再生時間4秒後に通常の所持数表示へ戻ります。一時停止中は表示を保持します。

車内では、接続が切れたプラグが出口未接続、形の異なる素材と赤線が素材違い、空箱が原料・弾薬・燃料切れ、詰まった箱が満載を示します。問題のあるマスに表示し、屋根を閉じると隠れます。搬送待ちのベルト全部には印を付けません。アイコンは配置操作を妨げません。

設備にカーソルを合わせるとヘッダーの設備欄に状態と関連素材を表示します。砂時計は入力待ち、時計は加工中、遮断板は出口待ち、チェックは搬送可能です。原料在庫は空なら赤、満載なら金。外観の弾薬・燃料の数値も空なら赤くなります。

## 音量と効果音

Escメニューの「音声」でミュート／解除、真鍮のつまみで音量を0〜100に調整します。初期値は35。設定はuser://audio_settings.jsonに保存し、次回起動にも引き継ぎます。保存に失敗するとメニュー最下部に「音量保存失敗」を表示し、その回の音量変更は有効なままです。破損時は.bakを試し、両方読めなければ初期値で開きます。

走行中のエンジン、加工完了、砲撃、着弾・被弾、回収に加え、配置・接続・装甲防護・報酬・連続撃破をそれぞれの音で表します。燃料切れで走行が止まればエンジン音も止まります。Space・Escで停止したとき、撤退・ラン切替・保存からの復帰時も古い音を止めます。ミュートしてもゲームは進みます。

## 画面サイズ

最小ウィンドウは960×628です。1440×940の配置比率を保って拡大・縮小し、画面比率が異なる場合は余白を入れます。960×628、1024×768、1280×720、1440×940、1920×1080で実クリック・配置・視点・Tab・Escを検証しています。

## ゲームデータの書き出し

次の手順はGodot 4.7でPCKを書き出し、空の作業フォルダから起動・生産・射撃・走行を自動確認します。

~~~sh
python3 tools/export_pack.py --godot /Applications/Godot.app/Contents/MacOS/Godot
~~~

出力はbuild/mfv03.pckと検証情報・SHA-256を含むbuild/mfv03-manifest.jsonです。試験コード・プレビュー画像・作業用ツールはPCKに含めません。PCKはGodotランタイムが必要なゲームデータで、単体アプリではありません。

~~~sh
/Applications/Godot.app/Contents/MacOS/Godot --main-pack /absolute/path/to/mfv03.pck
~~~

macOSの書き出しプリセットも付属します。単体アプリの書き出し・実行確認は対応する書き出しテンプレートの導入後に行います。現時点では署名や公証を行っていません。


## macOS単体アプリの書き出し

Godot 4.7.2の公式Export Templatesを導入し、次を実行します。

~~~sh
python3 tools/export_macos.py --godot /Applications/Godot.app/Contents/MacOS/Godot
~~~

build/MFV03.zipに、Apple Silicon・Intel両方の実行ファイルを含むアプリを生成します。展開したAMMO LINE LAB.appはGodotエディターを別途必要としません。内部名は既存の保存先との互換性のため維持しています。

ビルドは一時フォルダへ展開し、ソースを参照しない画面なし／画面あり起動を検証します。mfv03-macos-manifest.jsonにGodot版、コミット、変更有無、SHA-256を記録。署名・公証なしのローカル試作版です。Intel側は実行ファイルの同梱のみ確認し、実機動作はApple Siliconで検証しています。
