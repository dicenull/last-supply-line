# 装備の役割と供給コスト

[装備・ドロップへ戻る](EQUIPMENT.md) · [現行28種類の性能CSV](../data/equipment_items.csv)

新規入手する装備は、設置装備16系統と車体パーツ12種類です。レベルや僅かな倍率だけが異なる派生品を抽選・報酬・ショップ・タイトル図鑑から外し、左右の標準副砲は汎用副砲にまとめました。品質はノーマル〜レジェンダリーの4段階を維持します。旧312型式のIDは保存互換用に残り、すでに所持している旧型式はそのまま使用できます。

装備の完成判定、セット判定、組み合わせ専用ボーナスはありません。各装備が持つ効果と消費を個別に計算します。複数を載せると弾薬・燃料・面積・移動速度の制約も重なるため、十分な供給と運用が必要です。

## 設置装備16系統

数値はノーマル品質です。副砲は専用の弾倉と給弾ラインが必要で、設置方向の前方±30度を狙います。

| 装備 | 特徴と代償 |
|---|---|
| ホチキス汎用副砲 | 1射1発、1.5秒間隔。単体への低消費射撃 |
| ヴィッカース式連装砲 | 0.65秒間隔、射程24m。近距離の弾薬消費が速い |
| 長砲身対戦車砲 | 対装甲威力3、2発消費、2.4秒間隔、射程48m |
| 滑腔迫撃砲 | 威力2、半径4m、2発消費。3秒間隔 |
| 試製近接迎撃砲 | 射程20m内の敵砲弾を1発消費で迎撃。敵車両には攻撃しない |
| 多銃身斉射砲 | 2発を使って前方3標的へ射撃。単独標的では効率低下 |
| 試製誘導砲 | 2発と燃料0.30を使い9m以内へ2回連鎖。燃料不足で停止 |
| リベット増加装甲 | 全被害−25%、速度−12% |
| シュルツェン装甲 | 爆発・地雷被害−55%、速度−6%。通常弾・衝突の軽減なし |
| ルーツ式過給機 | 速度+40%、走行燃料消費+50% |
| 管式熱交換器 | 走行燃料消費−35%、速度−8% |
| 光学合致測距儀 | 全砲射程+10m、砲塔旋回−18% |
| ウォーム砲塔駆動機 | 砲塔旋回+80%、速度−6% |
| 門型回収クレーン | 3撃破ごとに廃材2・石炭1を追加ドロップ。速度−12%、砲塔旋回−15% |
| 着発榴弾信管 | 全砲爆発半径+4m、1射の消費砲弾+1発 |
| 回転弾倉装填機 | 射撃間隔−45%、消費砲弾1発あたり燃料0.16 |

迎撃砲は短砲身防御砲に着想を得た架空装備です。装填機の燃料消費は1射の消費砲弾数に比例し、信管で増える分も含みます。迎撃にも同じ消費規則が適用されますが、信管の爆発範囲は迎撃では役立ちません。弾薬か燃料が不足すると、その射撃は資源を消費せずに待機します。走行燃費の改善はプレス・装填・誘導砲の燃料消費を減らしません。

## 主砲と生産設備

| 主砲 | 対装甲威力 | 1射の弾薬 | その他 |
|---|---:|---:|---|
| 標準6ポンド型 | 1 | 1 | 拾った交換品は装填間隔−8%、射程+2m。初期装備は基礎性能 |
| 長砲身75mm型 | 4 | 2 | 射程+12m、射撃間隔+18% |
| 105mm型榴弾 | 3 | 3 | 爆発半径4m、射程−4m、射撃間隔+22% |

対装甲威力はボスの耐久値を削る量です。通常敵は従来どおり1発で倒せるため、高威力砲を雑魚へ使うと消費が重くなります。品質は威力に掛けて整数に丸めます。初期主砲は威力1・消費1です。

動力プレスは鋼材1個と燃料0.30から砲弾2発を1秒で製造します。完成品を2発とも送り出すまで次の鋼材を受け付けません。通常プレスは燃料不要で鋼材1個から砲弾1発を2秒で製造します。高炉は石炭を消費して精錬を早めます。いずれも製造物は搬送路を通って弾倉へ届く必要があります。砲弾庫・燃料庫・分岐器は供給の偏りや消費の山を吸収します。

## 設計・検証用の5例

以下はゲーム内のセットや完成条件ではなく、独立した機構から生まれる運用例です。部分的な組み替えでも各装備の効果は変わりません。

| 運用例 | 組み合わせとライン | 強み | 破綻する条件 |
|---|---|---|---|
| 動力弾幕 | 装填機、速射副砲、動力プレス、精製機・燃料庫 | 速い補給で射撃頻度を維持 | 走行・増産・装填が同じ燃料を使う。燃料枯渇で停止 |
| 機動狙撃 | 長砲身主砲、測距儀、軽量履帯、砲弾庫 | 長射程からボスの装甲を削り移動 | 近距離で旋回が追いつかず、雑魚にも2発消費 |
| 面制圧 | 榴弾主砲、信管、迫撃砲、並列生産・備蓄 | 密集敵と装甲目標を同時に攻撃 | 主砲1射4発、補給が細いと弾切れ。散開敵には非効率 |
| 移動要塞 | 増加装甲、耐爆装甲、迎撃砲、防御ブロック、迎撃用の独立給弾 | 被弾軽減と前方の敵弾迎撃 | 遅く、射界外や補給切れに弱い。迎撃弾は敵を倒さない |
| 回収巡航 | 回収クレーン、熱交換器、高効率エンジン、通常プレス | 回収した廃材・石炭を長く運用 | 火力や機動性を犠牲にする。現地回収できなければ補給されない |

## データ・保存・検証

現行設置装備の調整値は `data/equipment_current.json`、車体パーツは `data/vehicle_parts.json` にあります。`python3 tools/generate_equipment.py` がゲーム用定義と現行28種類のCSVを生成し、`--check` で一致を検証します。旧型式は archetypes と生成規則から互換用に生成します。

保存形式18は動力プレスの2発出力と飛翔中の砲弾威力を保持し、形式1〜17も読み込みます。古い飛翔弾に威力フィールドがない場合は従来の1ダメージで再開します。弾薬・燃料の同時消費、ボスへの実ダメージ、範囲攻撃、迎撃の射界、現物回収、品質によるコスト不変をネイティブテストで検証します。

## 配置による発動条件

追加装甲・耐爆装甲は占有枠のいずれかの辺が車体外周に接していると有効です。過給機・熱交換器は占有枠の辺でエンジン口に隣接する必要があります。斜めの接触は含みません。

装填機・榴弾信管は、砲弾製造機または弾薬備蓄庫から主砲・副砲へ届くパイプの辺に隣接すると有効です。パイプの向き・分岐・フィルター・副砲の外周給弾口を含めて判定します。隣のパイプが孤立していたり、途中に燃料用フィルターがあったりすると発動しません。備蓄・弾倉が空でも接続条件は満たせますが、発砲には従来どおり実際の弾薬と燃料が必要です。

条件を満たさない装備も配置できます。無効な間は性能補正も追加消費も適用せず、配置プレビューと設置枠を琥珀色にします。Eの行と説明、Qの効果表示でも判別できます。ラインの破断・修復や設備回転に追従して再判定します。設置場所未指定の条件付き装備はQで効果を見込まず、配置先を選ぶとその位置の差分を表示します。旧型式にも同じ系統の条件を適用します。
