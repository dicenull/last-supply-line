# 保存・再開

分岐フィールドでは道・目的地・障害物を同じ配置で復元し、到着後の選択も保持します。保存形式はversion 20で、従来のversion 1〜19も読み込めます。資源地帯・敵密集地・ショップの種類、ショップの商品と購入済み状態も保存します。

version 19は配置可能な廃材・石炭備蓄ブロックに対応します。既存の固定原料口と古い設備一覧は維持します。

version 18は動力プレスの砲弾2発の出力在庫と、飛翔中の主砲・副砲の威力を保存します。旧装備のIDは維持し、旧形式の飛翔弾は従来の威力1で復元します。

version 13は装備なしの部位と構築カメラの移動量を保存します。旧データの未指定部位は従来の標準装備のまま復元します。装備中アイテムと空部位の矛盾、空部位の重複、不正なカメラ位置は読み込み前に拒否します。

version 12は設置装備の90度単位の向きも保存します。旧データの向きは0として復元し、回転後の占有範囲とアイテムの向きが一致することを読込前に検証します。車体4部位の換装状態も保存し、復帰時に性能と外観へ反映します。

新規コースは`landscape_version=1`とシードから景観・迂回路・ランドマークを復元します。この指定がない既存の保存は、元の道路・障害物配置で再開します。保存の途中で地形が入れ替わることはありません。

## 開始・保存・再開

スタート画面には「はじめる」「続きから」「設定」をまとめています。難易度と音量は「設定」、配置保存・読込・取り消し・テンプレート・カメラ操作はゲーム中の「配置・車両」、過去の結果は「出撃履歴」に分かれています。戻るボタンかEscで親画面へ戻れます。

保存がないときの「続きから」、配置ファイルがないときの読込、履歴がないときの取り消しは無効です。保存結果はメニュー最下部に表示します。
Escでメニューを開くと生産・走行・戦闘を停止します。「ゲームに戻る」またはEscで元の再生状態に戻ります。「ランを保存」で現在のランを保存し、成否をメニュー最下部に表示します。

続きからは、配置・原料・加工中の物資・敵・飛翔弾・装備・選択候補まで復元し、停止状態で開きます。Spaceで続行してください。戦闘中の保存はラインを編集できる状態で復帰しますが、装備品の設置・移設・取り外しは次の出撃準備まで固定されます。移動キーの押下状態は引き継ぎません。ショップから再開した場合は買い物を続けられます。保存はuser://run_save.mfv、直前のバックアップは同名.bakです。主保存が破損していればバックアップを試し、どちらも読めなければ現在のゲームを変更しません。

終了アイコンとウィンドウを閉じる操作は、プレイ中なら保存成功後に終了します。保存できない場合は終了せずメニューに留まります。起動直後のメニューから終了する場合は、以前の保存を上書きしません。

配置だけの保存先は`user://ammo_layout.json`です。ラン全体の中断保存とは別に扱います。配置ファイルversion 3は車内レイアウトの世代も記録し、固定設備が異なる配置は読み込みません。旧version 1は旧車内の配置として扱います。装備品の移設や入手には使えず、装備の占有枠と衝突する配置も拒否します。

ブラウザ版の保存先と終了操作は[Web版の手順](../web/README.md#ブラウザでの操作)を参照してください。

## 出撃履歴

勝利・敗北・撤退時に結果を保存し、「出撃履歴」画面に直近2件を表示します。左から結果アイコン、シード、クリア数／5、製造砲弾数です。最大100件をuser://run_history.jsonに保存し、直前の.bakを保持します。保持中の同一シードは最初の結果を残し、保存を読み直しても重複追加しません。履歴の破損時はバックアップを試します。保存失敗はメニュー最下部に表示します。

## 配置テンプレート

「配置・車両」画面の「配置テンプレート」には出撃時の配置を3行で表示します。初期の見本に加え、1戦クリアで弾薬2系統、3戦クリアで弾薬庫2基付きの配置図を開放します。クリア直後に図面＋1が表示され、開放はその場で保存されます。敗北・撤退しても失いません。

配置テンプレートの行を押すと配置を置き換えます。金枠と「選択中」が現在と一致する配置です。鍵付きの行には必要クリア数を表示します。戦闘中や次戦の準備中にも使用でき、弾薬・燃料と無変更の設備の物資を保持します。配置した直後なら「配置・車両」の取り消しで戻せます。

配置テンプレートは既存設備の組み方を保存したもので、全構成を初回から手組みできます。2系統は生産量、弾薬庫付きは満載後の予備弾16発に重点を置きます。原料・完成品・耐久・設備上限へのボーナスはありません。燃料ラインは全図面共通です。新ランと出発前の難易度変更では標準ラインと初期素材に戻ります。テンプレート適用は現在の配置との建設費の差額を精算します。

設備設計図・配置テンプレートの解放状態は履歴と同じプロフィールファイルに独立保存され、古い結果が100件の保存範囲から外れても残ります。以前の履歴ファイルは記録されたクリア数から配置テンプレートを移行します。新設備の解放は更新後の新しい死亡から始まります。古いランの保存を読んでも、設備設計図の恒久解放は巻き戻りません。旧保存の配置・素材は保持し、報酬選択待ちは装備の抽選へ移行します。

## 装備と旧ランの互換

version 10以降は車内レイアウトの世代、装備の個体ID・系統・品質・位置・取り外し中の保管弾、次の個体IDを保存します。出撃済み状態から装備の固定も復元します。個体IDの重複、未知の品質、枠の重なり、装備と給弾口の不一致、弾薬の二重保持などは読込前に検証し、不正なデータで現在のゲームを上書きしません。

version 1〜9のランは旧車内・旧装備方式を保ち、途中で中央配置や装備アイテム方式へ置き換えません。そのランを終えるか新しいランを始めると、中央の原料区画・2×2主砲弾薬入れ・最後尾への給油・装備一覧を使う現行方式になります。旧ランの途中でも作られる保存ファイル自体はversion 20です。

version 11は300種類の装備型式を扱います。version 10の17種類はLv.1標準型として同じIDを維持し、所持品・装填弾・設置位置を引き継ぎます。特性の異なる同系統品の重複設置は拒否します。保留中の報酬やショップ商品は再抽選せず保存された候補を使います。

version 14では初期原料区画の囲い9マスを通常の防御ブロックとして保存します。3回分の耐久、破壊跡、修理、撤去を既存の防御処理で扱います。version 10〜13の現行車体は、従来暗黙だった固定壁を読み込み時に一度だけ防御ブロックへ移行します。version 14以降では撤去した囲いを再生成しません。

version 15は面ごとの集計済み記録、累計撃破数・最大コンボ・作戦時間・製造砲弾を保存します。クリア画面はロード後も同じ結果を表示し、二重加算しません。旧保存に存在しない過去の成績は推測せず、「旧セーブ：集計は更新後の面から」と表示します。

新規の最終面は `final_base_version=1` の大型基地1か所です。既存チェックポイントの道路・目的地は変更しません。基地正面のボスは24発耐久で、撃破後に基地内の受け渡し区画に到着すると直接クリア画面へ進みます。

version 16では新しいランの通常面に6種類の道路形状を導入します。形状IDと生成方式の版を保存し、ロード時に道路・目的地・景観を同じ配置で再現します。形状情報を持たない既存セーブのマップは変更せず、次に新しく生成する面から適用します。最終面の単一大型基地・ボス配置は維持します。

version 17では初期のギア・エンジン・履帯・主砲を装備中の所持品として登録します。初期品は基礎性能に含まれ、追加補正はありません。旧セーブの暗黙の初期品も読み込み時に登録し、装備なしの部位と交換済みの部位は保持します。移行用に初期品4個分の保存枠を確保しています。

version 20は主砲の2×2給弾口の位置を保存します。version 19以前は元の位置から再開します。副砲同士の設置枠の重なりを許可し、独立した給弾口と装填弾数は保持します。上下段は保存された配置から再計算します。

version 20では初期資材ブロックも通常の撤去可能な設備です。配置ファイルversion 3にも撤去状態を保存します。旧配置は元の資材口を保って移行します。
