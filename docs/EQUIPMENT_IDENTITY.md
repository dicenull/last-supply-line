# 装備名・外観・換装比較

現行16系統の設置装備と12種の車両パーツに、一覧へ表示する固有名と3Dモデルを用意しています。フィールドのドロップ、倉庫のプレビュー、車体上の設置装備は同じモデル生成処理を使用します。主砲と履帯は実車体の可動部にも型式の特徴を反映します。

## 史実からの着想

実機の厳密な復元ではなく、歴史上の機械構造を低ポリゴンで表現したゲーム用の架空装備です。年代・国籍を混在させ、性能・レベル・品質・換装の互換性はゲーム専用としています。

| 着想 | 表現した特徴 | 参考資料 |
|---|---|---|
| ホチキス6ポンド砲 | 短砲身、砲耳、防盾、砲尾 | [Australian War Memorial: 6 Pounder Hotchkiss](https://www.awm.gov.au/collection/C240439) |
| ヴィッカース水冷機銃 | 砲身を覆う水冷筒、給弾箱、配管。連装化はゲーム用 | [National Army Museum: Vickers machine gun](https://collection.nam.ac.uk/detail.php?acc=1967-10-47--1) |
| Maybach HL230 | V型12気筒と上部の2つの大型エアクリーナー | [The Tank Museum: Tiger 131 hull](https://tankmuseum.org/article/hull-tiger-131/) |
| GM 6046 | 並列に置かれた2基の直列6気筒 | [The Tank Museum: M4 Sherman Fury](https://tankmuseum.org/tank-nuts/tank-collection/m4-sherman-fury/?country=all&era=WW2&tname=&tpage=3) |
| Duckbill end connectors | 履帯の外側へ突き出した拡幅部 | [US Army, The Ordnance Department: On Beachhead and Battlefront](https://www.govinfo.gov/content/pkg/GOVPUB-D114-PURL-gpo84071/pdf/GOVPUB-D114-PURL-gpo84071.pdf) |

変速機は常時噛合の平行軸、遊星歯車の太陽歯車・遊星歯車・外輪、二重差動の左右ハウジングを作り分けています。主砲は6ポンド型、長砲身75mm型、短く太い105mm型。設置装備はリベット装甲、シュルツェン、管式熱交換器、光学合致測距儀、ウォーム駆動、門型回収クレーンなどの構造が着想です。「試製誘導砲」は架空の電撃兵器で、史実の実用装備ではありません。

型式末尾の `H-L-05B` などはゲーム独自の識別番号です。数字はレベル、Aは標準型、B/Cは各系統の特性を表し、史実の制式名称ではありません。砲身・防盾・筐体の寸法、照準器、給弾箱、配管、補強材がレベルと特性に応じて変わります。設置時は実頂点を測って縮尺を決めます。副砲は枠を越えて大きく表示し、干渉時は上下段へ振り分けます。

名称と着想は `data/equipment_identity.json`、車両パーツは `data/vehicle_parts.json`、生成モデルは `scripts/item_model.gd` にあります。`python3 tools/generate_equipment.py` で名前をランタイムデータとCSVへ反映します。

## パラメータの読み方

Qは全14項目をタブなし・スクロールなしで一覧表示します。各項目は「現在値 (装備補正) (選択差)」です。補正と変更差分は `(+3.0)` のような括弧付き数値で、良い効果は緑、悪い効果は赤です。

装備モデル・ギアなどの一覧と装備操作はEにまとめています。未装備の車体パーツには「換装」があり、共通アクションは未設置ならスクラップ、設置・装備中なら「しまう」に切り替わります。押している間に行が更新されても、押し始めたアイテムと操作を維持します。

QとEは独立して開閉でき、狭い画面では片方ずつ表示します。設置位置を選んでいる間もQを表示できます。倉庫と図鑑はページ送りで全品にアクセスします。

タイトルの「アイテム図鑑」では、未入手を含む現行28種をジャンル別タイルで閲覧できます。選択した品を左に大きく表示し、「性能 / 由来」を切り替えて読めます。ゲームの所持品やセーブは変更しません。

レア度の色は識別プレートや小さなリングだけに使い、金属・塗装の基本色は維持します。上位レア度には補強板、冷却フィン、追加機構が付き、図鑑・倉庫・ドロップ・実際の設置で共通の形状を使います。内部装備モデルの余白は4.5cmです。副砲は従来の車内サイズの2倍の幅・高さ2.6に拡大し、給弾口の位置を保ったまま二段に配置します。
