# 操作・画面表示

[READMEへ戻る](../README.md)

## 最初の出撃

起動後はスタート画面の「設定」で難易度を選び、戻って「はじめる」を選びます。難易度は第1戦の出発前に変更でき、ラン途中では固定です。保存したランを再開する場合は「続きから」を選びます。初期配置には弾薬と燃料の見本ラインがあり、砲弾・燃料は在庫0、停止状態から始まります。構築が済んだら **Space** またはフッターの「出撃」で戦闘へ進みます。生産と射撃が自動で始まり、車内では戦闘中もラインを編集できます。自機は **WASD／矢印キー** で移動します。**B** で車内／戦場を切り替え、**Esc** で保存などのメニューを開けます。

## 操作

スマートフォンは横持ちで操作します。左のパッドを上下に動かすと前後進、左右で旋回し、別の指で画面下のボタンも押せます。「設備」で建設種類を選び、配置する場所をタップ。「倉庫」の設置物をタップして設置場所をタップすると配置、「収納」を選んで装備をタップすると取り外せます。車体パーツは部位タブで選び、「換装」で取り付けます。設置物は選択後に回転ボタンで90度ずつ向きを変えられます。設置位置の選択中に「倉庫」を押すとキャンセルできます。タイトルとメニューは縦向きでも操作できます。メニューと倉庫は端末共通の表示で、収まらない部分は縦スクロールします。戦闘中に縦向きへ回転すると一時停止メニューを開きます。

柵や障害物にぶつかると、接触した車体の縁から火花が出ます。斜めに進入すると障害物に沿って擦りながら移動します。真正面で止まった場合は、Sで少し後退して向きを変えられます。押し続けても、実際に移動・旋回していない分の燃料は消費しません。

| 操作 | 動作 |
|---|---|
| Space／出撃・停止・再開 | 構築を確定して戦闘へ出撃。戦闘中は一時停止／再開 |
| WASD（ライン構築画面） | 画面の上下左右へカメラ移動。戦闘中の車内表示でも車体を動かさずに操作可能 |
| WASD／矢印キー（戦場画面） | 現在の車体方向にW/↑で前進、S/↓で後退。A/←・D/→でその場の超信地旋回。キーを離すと停止 |
| B／視点アイコン | 車内／外観の切替。進行は止まらない |
| Tab／Escメニューの屋根 | 車内側の装甲開閉と砲塔の透明度切替 |
| 左クリック・ドラッグ | 構築中の設備配置 |
| I／物資箱アイコン | 装備一覧を開閉。ジャンル別タブで選び、不要品を解体 |
| 車体パーツの換装／解除 | 出撃準備中にギア・エンジン・履帯・主砲を交換。「外す」で装備なしにし、部品を倉庫へ保管 |
| 装備一覧の行を左ドラッグ | 出撃準備中に空き枠へ装備を設置 |
| 設置済み装備を左ドラッグ | 出撃準備中に移設。装備本体と給弾口も追従 |
| 装備一覧の物資箱／スクラップ | 取り外し／解体。解体は未設置品のみ |
| 装備一覧右上の並べ替え | 品質順／入手順を切り替え |
| 装備一覧下部のスクラップ×個数 | 現在のジャンルのノーマル品を一括解体。見積もり後に確定／キャンセル |
| 右クリック・ドラッグ | 構築中の設備撤去 |
| 設置済み装備・パーツを右クリック | 出撃準備中に倉庫（所持一覧）へ戻す。装填弾も保持。一覧の装着済み行でも右クリック可能 |
| 0／撤去アイコン | 左端に固定された撤去ツールを選択 |
| 1〜7 | 現在のタブの表示中設備を選択（空き枠は無効） |
| タブのアイコン／8 | 搬送・選別、分岐、加工、備蓄、防御を切替 |
| 9 | 防御ブロックを選択（車内表示） |
| R | 配置予定の設備、選択中の設置装備を90度回転 |
| Q | カーソル下の設備・設置装備を回転 |
| 中ドラッグ／矢印キー（構築中） | 車内カメラの向き |
| ホイール（構築中） | 車内カメラのズーム |
| Escメニューの白旗 | ランを撤退終了 |
| 終了後の外観画面でR／回転矢印 | 新しいランの準備へ |

構築中にマスへカーソルを合わせると、選択設備の半透明プレビューを表示し、山形の蓋で出力方向を示します。Rで配置予定を90度ずつ回転し、クリックすると表示中の向きで設置します。分岐器は各出力先を表示し、置けない場所や素材不足では赤くなります。コンベアは角形パイプで、設置後も天面の山形の継ぎ目が流れる向きを示します。

パイプは隣接設備の搬送方向に合わせて直線・L字・分岐へ自動で形状が変わります。設備の接続口も同じ高さの継ぎ手でつながります。回転・撤去・部位破壊に合わせて接続表示が更新され、配置プレビューにも接続予定の形を表示します。

ライン設備は構築中・戦闘中とも配置・撤去・回転ができます。装備品の設置・移設・取り外しは出撃準備中だけで、出撃後は一時停止しても変更できません。次戦の準備で再び変更できます。未設置品の解体は戦闘中・報酬選択中・ショップ内でも可能です。[装備の説明](EQUIPMENT.md)を参照してください。戦闘中は **B** で車内を表示して編集します。配置読込・取り消し・見本適用でも装填済み弾薬・燃料・無変更の設備の物資を保ち、生産と戦闘を続行します。変更したマスの物資は失います。道中の分岐を運転して目的地を選び、到着後にアイテム報酬を選ぶと次戦の構築に戻ります。ショップではその前に買い物ができます。
配置の保存・読込・全撤去・取り消しはEscメニューの「配置・車両」にまとめています。出撃準備中と戦闘中に使用でき、装填済みの弾薬・燃料を保ちます。装備品の位置は変更しません。見本の再配置は「配置テンプレート」の標準配置から行います。
屋根を閉じた車内では、見えない床を誤編集しないよう配置を無効にします。
戦闘中は移動だけを手動で操作し、索敵・照準・射撃・生産は自動です。Wで車体の向いている方向へ前進、Sでそのまま後退します。A/Dは左右の履帯を逆方向に動かす超信地旋回で、車体の中心位置を動かさず左／右へ向きを変えます。W/SとA/Dを同時に押すと曲がりながら走行します。旋回だけでも履帯の走行量に応じた燃料を消費します。無入力では停止し、燃料切れでは前後移動も旋回もできませんが、生産と在庫弾の射撃は続きます。車内の確認中も移動キーは有効です。

## 戦場の表示

盾は耐久、交差砲身は撃破数、砲弾は装填在庫、燃料缶は燃料、方位アイコンは目的地までの距離です。
右上のミニマップは道の分岐・自車の向き・目的地のアイコンを表示します。物資箱は資源豊富、赤い交差砲身は敵密集、ひさしのある店はショップです。現地にも同じアイコンを表示します。ミニマップは表示専用で、行き先は実際に運転して選びます。複数の目的地がある場合、距離欄には最も近い搬入ヤードまでの距離を表示します。
距離欄はゴール区画までの最短距離を「あとNm」で表示し、区画内では「あと0m」になります。横に逸れると横方向の距離も反映し、施設の横まで来ても区画外なら0mになりません。Bの戦闘画面では自車両を左下に置き、右上へ続く進路を広く見渡せます。敵は道路前方の画面外から走って入り、接近型は正面へ、迂回型は反対側の車線へ寄り、重砲は少し先から迎撃します。射撃は画面内で各砲の射程へ入ってから始まります。主砲は基本36m、長砲身砲は48m。敵の狙撃砲・迫撃砲・指揮車は48m、ほかは42mから攻撃を開始するため、増設砲と早い弾薬供給に意味があります。
ヘッダー左側の「1/5」などの数値が現在の戦場。敵上の小さな目盛りが敵耐久、金色の輪が自動照準先です。状態表示は1行にまとめ、汎用の操作完了チェック表示は省いています。
右側パネルをなくし、中央の車内／戦場を横幅いっぱいに表示します。ヘッダーは表示専用で、耐久・弾薬・燃料・距離・原料・設備状態をまとめています。フッターの左側は種類別のタブと設備選択の2段です。撤去は左端の0番に固定し、回転・収納・装甲開閉・視点切替・出撃・Escメニューもフッター内に配置します。マウスとタッチは同じアイコンを使い、狭い画面ではカテゴリ・設備・操作の3段に並べ替えます。戦場表示は操作の1段になり、移動パッドと重なりません。戦場表示では移動キーと車内編集への切替を表示し、車内表示では戦闘中も設備ツールを使えます。配置管理・テンプレート・カメラ初期化・装甲開閉はEscメニューの「配置・車両」にまとめています。音声・難易度は「設定」、履歴は「出撃履歴」、撤退は一時停止画面にあります。戻るボタンかEscで親画面へ戻り、一時停止画面でEscを押すとゲームに戻ります。報酬・ショップは背景を暗くした中央ポップアップに表示し、フッターを広げたり入れ子にしたりしません。試運転用の計器と発射速度切替、試運転リセットは表示しません。
赤い輪は予告砲撃地点。移動して着弾地点から離れると回避できます。予測砲撃には途中で方向を変える判断も必要です。
被弾すると車体耐久に加え、着弾地点の近くにあるライン設備が最大1マス破壊されます。搬送路・生産機・分岐・備蓄庫が対象で、そのマスの物資も失います。無傷の系統と装填済みの弾薬は残ります。破壊跡は瓦礫と赤い×で表示し、Bで車内を見ると切れた場所を確認できます。戦闘中も素材を使って再建でき、画面右下のレンチボタンで一括修復できます。装備一覧を開いている間は一覧の左隣へ移動し、ヘッダー・フッター・一覧に重ならない位置を保ちます。コースクリア時に、報酬を選ぶ前に全設備を無料修復します。破壊時の位置・設備種別・向きも中断保存に含むため、再開後も元のラインへ復旧します。破壊による素材返却はなく、敗北・撤退では修復しません。固定の原料口・エンジン口・主砲／副砲の給弾口はこの部位破壊の対象外です。
初期見本は改良の出発点です。第2廃材口から弾薬ラインを並列化すると後半の供給を増やせます。

## 回収・在庫・ラインの状態表示

雑魚敵の撃破では現地に廃材・石炭、ボス撃破では装備品をドロップします。補給地点の輪へ入ると装備品が地面に出ます。地面の3Dモデルへ車体中心が12m以内まで近づくと自動回収します。左上に装備アイコン・品質の色と目盛り・獲得数を短時間表示し、フッターの物資箱には所持数を表示します。取得通知は最大4枠で、同じ品の連続回収はまとめます。一時停止中は表示時間を保持し、新しいランと保存復帰で過去の通知を消します。**I**の一覧で確認し、スクラップのボタンで未設置品を解体すると廃材・石炭が増えます。素材の回収時はヘッダーの該当欄に現在量と「＋回収数」を1行で表示します。廃材・石炭はすべて回収します。旧保存の砲弾回収だけは装填容量を超えた分を「−積めなかった数」で表示します。近接する同種の回収は合算し、再生時間4秒後に通常の所持数表示へ戻ります。一時停止中は表示を保持します。

車内では、接続が切れたプラグが出口未接続、形の異なる素材と赤線が素材違い、空箱が原料・弾薬・燃料切れ、詰まった箱が満載を示します。問題のあるマスに表示し、屋根を閉じると隠れます。搬送待ちのベルト全部には印を付けません。アイコンは配置操作を妨げません。

設備にカーソルを合わせるとヘッダーの設備欄に状態と関連素材を表示します。砂時計は入力待ち、時計は加工中、遮断板は出口待ち、チェックは搬送可能です。原料在庫は空なら赤、満載なら金。外観の弾薬・燃料の数値も空なら赤くなります。

## 音量と効果音

「設定」画面の「音声」でミュート／解除、真鍮のつまみで音量を0〜100に調整します。初期値は35。設定はuser://audio_settings.jsonに保存し、次回起動にも引き継ぎます。保存に失敗するとメニュー最下部に「音量保存失敗」を表示し、その回の音量変更は有効なままです。破損時は.bakを試し、両方読めなければ初期値で開きます。

走行中のエンジン、加工完了、砲撃、着弾・被弾、回収に加え、配置・接続・装甲防護・報酬・連続撃破をそれぞれの音で表します。燃料切れで走行が止まればエンジン音も止まります。Space・Escで停止したとき、撤退・ラン切替・保存からの復帰時も古い音を止めます。ミュートしてもゲームは進みます。

## 画面サイズ

最小ウィンドウは960×628です。1440×940の配置比率を保って拡大・縮小し、画面比率が異なる場合は余白を入れます。960×628、1024×768、1280×720、1440×940、1920×1080で実クリック・配置・視点・Tab・Escを検証しています。
