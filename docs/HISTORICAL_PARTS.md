# WW1・WW2の史実パーツ

2026-10-30。英・仏・独・米・ソ連・日本の6か国から12種類を追加。既存28種類と合わせて現行40種類、保存互換用の定義は324 ID。

## 入手と表示

- 基本レア度は入手時の下限。敵ドロップはまずレア度を抽選し、その品質で出現可能なパーツを選ぶ。低品質の抽選をレジェンダリーへ昇格させない。
- 航空支援は引き続き各候補90%レア・10%レジェンダリー。レジェンダリー専用品は該当品質の候補にだけ入る。表示と取得で再抽選しない。
- ショップは価格を基本レア度に合わせて32 / 48 / 80 / 96廃材とし、既存の最低アンコモン品質とパーツの基本レア度の高い方で販売する。
- 図鑑では全40種類を所持状況によらず表示。史実品の基本レア度をモデルと名称色に反映し、性能・国・時代・車両・由来を確認できる。
- レア度による色は小さな識別プレートに限定。品質の構造差も維持する。フィールド、倉庫、図鑑、航空支援、リザルトは共通モデルを使う。
- 車体上でもエンジン・変速機をそのモデルで表示。史実主砲は元の砲身を置換し、実際の先端から発射する。史実履帯は元の足回りを隠して専用形状に交換する。通常品への換装で元の形状へ戻す。

## 実装と検証

定義は `data/historical_parts.json`、生成元は `tools/generate_equipment.py`、形状は `scripts/historical_part_model.gd`。`item_model.gd` から呼び出す。旧IDと旧保存は削除しない。

`historical_parts` は国・時代・出典、固有の形状、性能と代償、入手下限、8段を含む自動変速、換装反映、保存復元を検証する。`vehicle_parts`、`vehicle_parameters`、`equipment_progression`、`item_catalog_page` で関連経路を確認。すべてヘッドレス・最大4並列で実行する。
